## Вход и регистрация

### Вход в приложение
1. Введите **логин** и **пароль**
2. При необходимости включите **Запомнить меня** — приложение не будет запрашивать пароль при следующем запуске
3. Нажмите **Войти**

### Регистрация
1. Нажмите **Нет аккаунта? Создайте!**
2. Придумайте логин и пароль
3. Нажмите **Зарегистрироваться**

## Главный экран

На главном экране отображается карта с элементами управления.

### Кнопки управления (правая панель)
- **Слои** — выбор типа карты (OpenStreetMap или Satellite)
- **Геолокация** — показать текущее местоположение на карте. Повторное нажатие отключает отслеживание

### Боковое меню
Откройте меню свайпом слева или нажав на иконку **☰** в левом верхнем углу:
- **Профиль** — личные данные
- **Маршруты** — список сохранённых маршрутов
- **Руководство** — эта страница
- **Настройки** — параметры приложения
- **Выйти** — выход из аккаунта

## Создание маршрута

### Рисование нового маршрута
1. Нажмите кнопку **+** в правом нижнем углу
2. Тапайте по карте — каждое нажатие добавляет точку маршрута
3. Внизу экрана отображается **общая дистанция** в километрах
4. Для удаления последней точки нажмите кнопку **↩**
5. Нажмите **💾** чтобы сохранить маршрут
6. Нажмите **✕** чтобы выйти из режима рисования без сохранения

> **Подсказка:** при сохранении маршрута автоматически загружаются данные о высоте для каждой точки. Это может занять несколько секунд.

### Импорт маршрута
1. Откройте боковое меню
2. Нажмите **Импортировать маршрут**
3. Выберите файл в формате **GPX** или **KML**
4. Маршрут отобразится на карте

## Управление маршрутами

Откройте **Маршруты** в боковом меню чтобы увидеть список всех сохранённых маршрутов.

### Карточка маршрута содержит
- Название маршрута
- Дату и время создания
- Дистанцию в километрах
- Набор высоты в метрах
- Тип хранения — **☁️ облако** (сервер) или **📱 устройство** (локально)

### Действия с маршрутом
- **Выбрать** — отобразить маршрут на карте
- **Рассчитать** — рассчитать потребление воды и еды с помощью ИИ
- **Экспортировать** — сохранить маршрут в формате GPX или KML
- **✏️** — переименовать маршрут
- **🗑️** — удалить маршрут

## Профиль

Личные данные используются для расчёта потребления воды и еды на маршруте.

### Заполните следующие поля
| Поле | Описание |
|---|---|
| Возраст | Полных лет |
| Вес | В килограммах |
| Рост | В сантиметрах |
| Пол | Мужской или женский |
| Темп бега | Минут на километр |
| VO2 max | Максимальное потребление кислорода, мл/кг/мин |

> **Подсказка:** VO2 max можно узнать из спортивных часов или рассчитать онлайн по результатам забега.

### Сохранение данных
- **Сохранить** — сохраняет данные на сервере
- **Сохранить на устройстве** — сохраняет локально для работы без интернета

## Настройки

### Интерфейс
- **Тема** — светлая или тёмная
- **Язык** — русский, английский, немецкий, украинский

### Карта
- **Карта по умолчанию** — OpenStreetMap или Satellite
- **Папка экспорта** — папка для сохранения файлов маршрутов

---

## Работа без интернета

PathFinder поддерживает **офлайн режим**:
- Ранее загруженные маршруты доступны без подключения
- Новые маршруты сохраняются локально и синхронизируются при восстановлении связи
- Данные профиля доступны если были сохранены на устройстве
